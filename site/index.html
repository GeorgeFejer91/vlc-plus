VLC+

Video playback with continuous valence and arousal input, Flubber, a 2D grid, or an affective face morph map.

This repository includes the complete Remote LSL Recorder desktop app and its browser controller. Build and run both apps from one checkout; no second repository is required.

Start video and recording together

In the desktop Recorder, open VLC+ setup and enter a local video path and an unused control port. Apply a participant ID and recording folder, select any additional streams, then choose the orange cone button, Start VLC and record.

VLC+ opens paused. Recorder identifies that player's affect and marker streams, starts recording every selected stream, waits for their XDF headers, and then begins playback. Stop the video before Stop recording to retain its terminal marker. Recording errors retain the partial file and show its path.

The browser controller pairs with the desktop Recorder after you enable phone access and approve the connection. Files, acquisition and XDF recording remain on the computer.

VLC+ hotkeys

Use these with the VLC+ player or video focused. Dialog fields retain normal editing keys. With affect arrows on, VLC's arrow seek and volume shortcuts are reserved; plain arrows change valence and arousal, including while paused. Alt+F restores normal VLC arrows.

CLI controls

Launch a controllable player with vlc.exe --extraintf=rc --rc-host=127.0.0.1:42123 --rc-quiet --flubber-input=arrows. The source helper changes a running player:

./vlc-qt/flubberctl.ps1 -Port 42123 -Command 'primary flubber'
./vlc-qt/flubberctl.ps1 -Port 42123 -Command 'primary grid'
./vlc-qt/flubberctl.ps1 -Port 42123 -Command 'primary face'
./vlc-qt/flubberctl.ps1 -Port 42123 -Command 'input arrows'
./vlc-qt/flubberctl.ps1 -Port 42123 -Command 'input mouse'

Independent 30 Hz LSL sampling and the local CSV backup continue separately from drawing. This experimental software does not establish physical display onset or scientific timing qualification.
