# VLC+ 0.3.3 experimental

Alt+F reserves arrows for valence/arousal and restores VLC arrows on the next
press. Alt+G cycles Flubber, 2D grid and the selected affective face morph map.
The player includes quick layout, size, panel-height, rating-step, face-speed
and grid-density shortcuts; see vlc-qt/README.md for the complete list and CLI.

The authorized Great Dictator sample remains bundled. The Rust worker still
owns independent 30 Hz LSL and video-local CSV; drawing never drives sampling.
This experimental player does not claim physical keyboard, display-onset,
scientific timing or full Planner-master execution qualification.
