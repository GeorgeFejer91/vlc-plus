original path and SHA-256. The extraction copied runtime C++/Rust, the patch and atlases unchanged.

while preserving the existing supported-input gate; its tests include actual

isolation from an already-running player. Other `adapted` entries cover
documentation, packaging and installer identity.
Git history records those adaptations.
The original full history stays in Affect Research; this is a reviewed source
snapshot, not a claim to have imported that repository's complete Git history.

The source selection is the latest stock-VLC Qt implementation at that branch.
It includes all three feedback modes, settings/menu integration, the C ABI
bridge, exact Cargo lock, panel checks and nine atlases. Recorders, obsolete
player prototypes, demo films, user data, generated binaries, old screenshots
and machine-specific validation receipts are excluded.

`createVlcFlubberAppearance(createFeedbackAuthoringSettingsV2(...))` with
`createDefaultResearchSettings()` input/visual defaults and
`createDefaultFlubberMappings()` from the eight original module dependencies
at that same upstream commit. No Planner implementation is shipped here.
